# 初始化 RepoFrame

读取仓库根目录 `PRD.md`，以及与产品定位直接相关的已有材料。缺少 PRD 时请用户提供需求材料；模板占位符不算已知事实。优先从已有内容提炼，不自行增加工程规范或技术约束。

将结果整理为 `.agents/docs/product.json` 所需的五个字段：

- `summary`：产品的一句话描述，字符串。
- `users`：主要用户，字符串。
- `coreRequirements`：核心需求，非空字符串数组。
- `constraints`：明确的长期约束，字符串数组；未提供则为空数组。
- `nonGoals`：明确不做的内容，字符串数组；未提供则为空数组。

展示具体提炼结果，只对材料不能确定的必要信息提问。获得用户对这份结果的一次确认后再写入产品文件；已有针对同一结果的明确确认无需重复询问。不要把调用本 Skill 本身当成对尚未展示结果的确认。

如果需要创建目录和入口，使用 `npx repoframe init`；已具备目录时无需再次运行。写文件前重新读取已有产品信息，保留无关扩展字段。除用户明确要求更新外，不覆盖已确认的产品信息。使用 UTF-8、两空格缩进和末尾换行；先写同目录临时文件再替换，若目标文件期间发生变化则停止覆盖并报告。

检查 `AGENTS.md` 引用 `.agents/state.json`、`.agents/docs/product.json` 和目标目录。初始化默认状态为 `{"mode":"default","activeGoal":null}`，不得重置已有工作状态，不创建示例目标，不修改原始 PRD。

完成后说明已写入的产品信息，并提示运行 `npx repoframe` 打开中文工作台。此 Skill 不调用特定 Agent SDK、模型 API 或调度系统。
